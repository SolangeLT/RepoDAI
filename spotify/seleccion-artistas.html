Consulta de canciones con sessionStorage

Guarda tu token temporalmente en sessionStorage, elige una canción y consulta la información del álbum y de los artistas desde la API de Spotify.

1) Guardar token

El token se guarda solo en la sesión actual de esta pestaña.

2) Seleccionar canción

La 4ta canción se agregó a partir de una URL pública de Spotify que contiene el ID de esta.

3) Resultado de la canción

Aquí aparecerá la información de la canción seleccionada.
